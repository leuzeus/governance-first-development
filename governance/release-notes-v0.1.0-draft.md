# Governance-First Development v0.1.0-draft

> Experimental proposal — tested only on ongoing projects; no completed full-lifecycle reference implementation yet.

This first draft publishes a repository-centered method for keeping project authority, intent, decisions, constraints, validation requirements, and evidence aligned with code written by humans and AI agents.

## Included

- Canonical method and 15-principle manifesto
- `EXPLORE`, `FAST`, `STANDARD`, `ASSURED`, and `EMERGENCY` profiles
- Maturity statement, risks, unknowns, and validation roadmap
- Prior-art review with earlier uses of governance-first terminology
- Lightweight authority, decision, evidence, and profile templates
- Fictional personal-project adoption example
- Author-owned `audit-project-governance` skill as an experimental reference implementation
- Repository authority map, contribution rules, validation script, and initial audit evidence
- Publication privacy gate covering current content, Git history, public identities, and binary metadata review

## Limits

No completed product has used GFD through a full lifecycle. The release contains no controlled evidence that GFD improves quality, speed, token use, maintenance, or auditability. Ongoing projects are sources of observations only.

The phrase "governance-first development" has prior public uses. This release proposes a specific synthesis and does not claim ownership of the expression or invention of its component practices.
