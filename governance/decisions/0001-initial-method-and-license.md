# Decision 0001: Publish GFD as an experimental MIT-licensed proposal

Status: accepted

Date: 2026-08-01

Authority: project owner, publicly identified as `LeuZeuS`

## Context

The project owner wants to publish a repository-centered governance method derived from practical AI-assisted development work and the earlier `audit-project-governance` skill. The method has not completed a full product lifecycle and the phrase has prior public uses.

The project owner confirmed authorship of the skill. No civil name, affiliation, organization, or research identifier has been provided.

## Options

1. Delay all publication until the method has a completed case study.
2. Publish a draft with narrow claims, visible limits, prior-art attribution, and a validation program.
3. Publish the method with maturity or standardization claims that the evidence does not support.

For licensing, the considered options were a simple permissive license, a reciprocal license, or no public license.

## Decision

Use option 2. Label the repository `0.1-draft` and display the required experimental status in both README files, `STATUS.md`, the future GitHub description, and release notes.

Use the MIT License for original repository content and the project-owner-authored audit skill. Attribute the public identity `LeuZeuS` until the owner chooses a different public author name. Do not invent an affiliation or legal identity.

## Consequences

The material can be used, modified, redistributed, sublicensed, and sold under the MIT notice. The method receives criticism earlier, but readers may still mistake a detailed repository for evidence of effectiveness. Repeated maturity warnings and claim-specific evidence rules reduce that risk without eliminating it.

The prior uses of the phrase must remain visible. The project cannot claim a trademark search, name exclusivity, scientific validation, or industrial maturity.

## Expected evidence

- License text and citation metadata validate locally.
- Source register records prior terminology and neighboring work.
- Repository audit confirms that current claims match `STATUS.md`.
- Public repository and release are created only after explicit owner approval of the pre-publication review.
