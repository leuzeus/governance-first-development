# Changelog

This project follows draft versions rather than claiming stable semantic compatibility before the method has been tested.

- Add a redacting publication privacy scrub for personal data, machine structure, Git history, public identities, and binary metadata.
- Add the attempt outcome integrity extension while retaining GFD `0.1-draft` experimental status.
- Separate execution status, gate result, proof status, product verdict, and failure classification.
- Add append-only attempt and outcome schemas, materiality rules, causal lineage, and generic cases A–H.
- Add a deterministic validator and negative tests for false product blame, premature correction validation, over-governance, and rewritten history.
- Version the reference audit skill independently from the method and add deterministic package/sync controls.

- Publish the initial working definition and manifesto.
- Define authority, decision, invariant, control, evidence, time, context, document, agent, friction, and audit practices.
- Define `EXPLORE`, `FAST`, `STANDARD`, `ASSURED`, and `EMERGENCY` profiles.
- Record prior art, exact-phrase collisions, maturity limits, and a validation roadmap.
- Add lightweight templates, a personal-project example, and the reference audit skill with provenance.
